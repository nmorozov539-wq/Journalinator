Grow and shrink while typing

Illustrative width stages at 220, 300 and 380 board pixels. At the cap, additional text increases height. Deletion follows the same rule in reverse. Actual main-pin position stays fixed through every change; these separate specimens illustrate dimensions only.

Not included

No migration, encrypted vault, hidden paragraphs, GM annotations, Location notes, actor linking, ranking, statistics screens, manual-save workflow or simultaneous co-editing. Private canvases and ordinary GM administration remain.
